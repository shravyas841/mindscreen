# Superseded Evidence Audit

This file previously asserted that every submission-readiness item was
satisfied, including PDF compilation and visual inspection. Those assertions
were stronger than the repository evidence and are withdrawn.

The current authoritative machine-readable evidence is
[`submission_evidence.json`](submission_evidence.json), generated by
`backend/run_submission_evidence.py`. It covers deterministic HRE cases, the
current constructed/team-labeled crisis-language conformance set, a deterministic constructed
weight-sensitivity analysis, and local in-process timing and Python heap
measurements. Raw fusion and post-HRE outputs are reported separately. It does
not establish clinical validity,
diagnostic accuracy, deployment latency, end-to-end latency, process RSS, or
performance on an independent participant dataset.

The complete current sensitivity output is stored in
[`current_weight_sensitivity.json`](current_weight_sensitivity.json); historical
raw files are isolated under `historical/` and remain provenance only.

The authoritative manuscript source is `mindscreen_ieee_paper.tex`. LaTeX
compilation and visual PDF inspection must be completed in an environment with
a working IEEEtran toolchain before submission.
